💡 交互式解题思维链（点击分步点亮图形）
🔹 步骤 1：判定相似三角形（A 字型经典模型）
因为四边形 DEFG 是正方形，所以对边平行：DG // BC。
平行于三角形一边的直线截其它两边，所截得的三角形与原三角形相似：
👉 故可得：△ADG ∽ △ABC
（已在画板中用绿色高亮虚线框出顶部的小三角形 △ADG，它与大三角形 △ABC 完全同构）
🔹 步骤 2：相似三角形核心性质（对应高之比等于相似比）
高线 AH 与 DG 交于点 P。因为 DG // BC 且 AH ⊥ BC，所以 AP ⊥ DG，即 AP 是 △ADG 的高线。
根据相似三角形定理：“相似三角形对应高的比等于相似比，等于对应底边的比”：
👉 AP / AH = DG / BC
（已在画板中将高线 AP 与底边 DG、全高 AH 与全底 BC 分别高亮标记）
🔹 步骤 3：设未知数并代入已知量列出一元一次方程
设正方形的边长为 x，则： DG = x，PH = DE = x，因此上半部分小高线为：AP = AH - x = 40 - x。
代入步骤 2 的比例式：
(40 - x) / 40 = x / 60
两边同乘两底的公倍数（或交叉相乘）：
60 · (40 - x) = 40 · x
2400 - 60x = 40x
100x = 2400
👉 x = 24 cm
🔹 步骤 4：提炼母题通用解法与中考秒杀口诀
若设任意三角形底边为 a，高为 h，内接正方形边长为 x：
由 (h - x) / h = x / a，去分母得 a · (h - x) = h · x ⟹ a·h - a·x = h·x ⟹ (a + h)·x = a·h。
由此解得通用公式：
🌟 x = (a · h) / (a + h)
两边同除以 a·h·x，还可以得到极具美感的调和倒数形式：1/x = 1/a + 1/h。

⚡️ 中考培优秒杀口诀：底高之积除以底高之和

凡是三角形内接正方形（或长宽比固定的矩形），只要知道对应底和高，不用重画辅助线，直接带入公式：

x = (底 × 高) ÷ (底 + 高)
