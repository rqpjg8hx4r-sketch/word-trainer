题目 7：三角形内接正方形边长求解

1 沿正方形上边切一刀
沿着正方形的上边 DG 水平切一刀，把大三角形分为上一半和下一半：
  • 上一半：小三角形 △ADG，底是 x，高是 (40 - x)。
  • 下一半：梯形 BCGD，上底 x，下底 60，高是 x。
2 每一半都翻倍（×2）变矩形
根据小学学过的“两个完全一样的图形能拼成长方形”：
  • 上一半 × 2：两个小三角形拼成矩形①，面积是 x × (40 - x)。
  • 下一半 × 2：两个梯形拼成矩形②，长是 (60 + x)，高是 x，面积是 x × (60 + x)。
3 乘法分配律：神奇合体抵消
看！矩形①和矩形②有一条边都是 x！我们把它们沿着边长 x 拼在一起：
总长 = (40 - x) + (60 + x) = 40 + 60 = 100！
其中的 -x 和 +x 刚好完全抵消了！拼合成一个宽是 x、长是 100 的大长方形，面积正是： x × (40 + 60) = 100x
4 天平对等：一步除法秒杀
原大三角形本来底是 60，高是 40。如果把原三角形整体翻倍（×2），面积本来就是：
原三角形翻倍 = 底 × 高 = 60 × 40 = 2400
两种拼法得到的翻倍总面积必须完全相等：
x × (60 + 40) = 2400
一步除法：x = 2400 ÷ 100 = 24 cm！

🌟 Alex 的超能秒杀口诀：

上下一翻倍，正负 x 全抵消！拼成大矩形，长是底加高！

x = (底 × 高) ÷ (底 + 高)
💡 进阶几何思维链（点击分步点亮图形）
🔹 步骤 1：判定相似图形（A 字型经典模型）
因为四边形 DEFG 是正方形，所以对边平行：DG // BC。
平行于三角形一边的直线截其它两边，所截得的三角形与原三角形形状完全同构（成比例）：
👉 故可得：△ADG ∽ △ABC
（已在画板中用高亮虚线框出顶部的小三角形 △ADG，它与大三角形 △ABC 完全同构）
🔹 步骤 2：对应高线比等于底边比
高线 AH 与 DG 交于点 P。因为 DG // BC 且 AH ⊥ BC，所以 AP ⊥ DG，即 AP 是 △ADG 的高线。
成比例图形的重要定理：“对应高的比等于对应底边的比”：
👉 AP / AH = DG / BC
（已在画板中将高线 AP 与底边 DG、全高 AH 与全底 BC 分别高亮标记）
🔹 步骤 3：设未知数并代入已知量列出方程
设正方形的边长为 x，则： DG = x，PH = DE = x，因此上半部分小高线为：AP = AH - x = 40 - x。
代入步骤 2 的比例式：
(40 - x) / 40 = x / 60
两边交叉相乘：
60 · (40 - x) = 40 · x
2400 - 60x = 40x
100x = 2400
👉 x = 24 cm
🔹 步骤 4：提炼通用秒杀公式
若设任意三角形底边为 a，高为 h，内接正方形边长为 x：
由 (h - x) / h = x / a，去分母得 a · (h - x) = h · x ⟹ a·h - a·x = h·x ⟹ (a + h)·x = a·h。
由此解得通用公式：
🌟 x = (a · h) / (a + h)
两边同除以 a·h·x，还可以得到极具美感的倒数形式：1/x = 1/a + 1/h。

⚡️ 超能秒杀口诀：底高之积除以底高之和

凡是三角形内接正方形，只要知道对应底和高，直接带入口诀公式计算：

x = (底 × 高) ÷ (底 + 高)
