📝 题目 12 题目重现

如图，四边形 EFGH 的面积是 66 平方米，已知 EA = AB，CB = BF，DC = CG，HD = DA，求四边形 ABCD 的面积。

核心定理：顺次延长各边 1 倍，
恒满足：SEFGH = 5 × SABCD
🔍 严密推导五步法 (公式清晰展示)
1 看左角 △EAH：连辅助线 ED。
因 HD = DA，ED 为中线，则 S△EDH = S△EAD；
因 EA = AB，DA 为 △EBD 中线，则 S△EAD = S△ABD。
故 S△EAH = 2 S△ABD。
2 看其余三角同理：连 AF, DF, CH 中线：
• S△FBE = 2 S△ABC
• S△GCF = 2 S△BCD
• S△HDG = 2 S△ADC
3 四周 4 角求和：
2(S△ABD + S△BCD) + 2(S△ABC + S△ADC)
= 2 SABCD + 2 SABCD = 4 SABCD。
4 大四边形总面积：
SEFGH = SABCD + 4 SABCD = 5 SABCD。
5 计算最终面积：
SABCD = 66 ÷ 5 = 13.2 平方米。

🪟 等积模型（拉窗帘）核心要领

两平行线之间的垂直距离（高）处处相等。当三角形的底固定在一条线上，顶点在另一条线上左右滑动时，就像拉窗帘一样，形状虽然剧烈变化，但底和高从未改变！

核心公式：
S = ½ × 底 b × 高 h （面积处处相等）
💡 实战应用与技巧

• 不规则多边形等积化简：遇到复杂的凹凸四边形，可以通过平行线滑动顶点，将其转化为简单的等积三角形。

• 梯形两腰三角形等积：在梯形 ABCD（AD // BC）中，△ABC 与 △DBC 同底等高同积，减去公共底 △OBC 后，立刻能证明两腰翅膀面积相等（即蝴蝶模型梯形性质）！

🌓 一半模型的核心两种形态
形态 A：底为一边，顶在对边
S阴影 = ½ × S平行四边形

形态 B：内部任意点连四顶
S上 + S下 = S左 + S右 = ½ × S总

无论点 P 在对边上如何滑动（形态 A），底都是一整条边，高都是四边形的高，面积必定占一半！
当点 P 处于内部任意位置（形态 B），两对对顶三角形的高之和等于四边形的总高，因此它们各自的面积和恒等于总面积的一半！

🦋 蝴蝶模型两大黄金法则
法则 1（任意四边形通识）：
头 × 尾 = 翅 × 翅 （S₁ × S₂ = S₃ × S₄）

法则 2（梯形特有性质）：
左翅 = 右翅 （S₃ = S₄）

在任意四边形对角线划分出的 4 个三角形中，对顶三角形面积之积永远等于两侧三角形面积之积！若上下两底平行（梯形），两侧翅膀面积更是严丝合缝完全相等。

⏳ 沙漏模型核心本质
相似比定理：
S上 / S下 = (a / A)² = (h₁ / h₂)²

沙漏形状上下两底平行，内错角相等，因此上下两三角形严格相似！
不仅对应底边成比例，高也成相同比例，故面积比为边长比例的平方（底乘高双倍放大）。

核心公式：
S黄 / S蓝 = (a × b) / (A × B)

1. 等积模型

别名：拉窗帘模型
S = ½ × b × h （同底等高）

平行线间距离（高）处处相等。顶点沿平行线滑动时，底与高不变，面积处处相等。

🌓

2. 一半模型

矩形与平行四边形
S(阴影) = ½ × S(平行四边形)

底为一边顶点在对边，或内部任意点向四顶引线上下和等于一半。

🦋

3. 蝴蝶模型

对角线交叉四分法
头 × 尾 = 翅 × 翅 (S₁×S₂ = S₃×S₄)

任意四边形对顶积相等；梯形中左右两翅膀面积完全相等！

⏳

4. 沙漏模型

X 相似比定理
S(上) / S(下) = (a / A)²

两底平行的交叉相似图形，面积比等于对应边长比的平方。

🐦

5. 鸟头模型

共角 / 互补角定理
S(小) / S(大) = (a × b) / (A × B)

两三角形共角或互补，面积比等于夹角两边乘积之比。题目12核心！

🕊️

6. 燕尾模型

三角形内点三射定理
S₁ / S₂ = S₃ / S₄ = d₁ / d₂

左右两大大三角形之比等于下方两小三角形之比，且等于底边截比。
