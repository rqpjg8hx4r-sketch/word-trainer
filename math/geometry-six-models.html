如图，四边形 EFGH 的面积是 66 平方米，已知 EA = AB，CB = BF，DC = CG，HD = DA，求四边形 ABCD 的面积。

核心定理：顺次延长各边 1 倍，
恒满足：SEFGH = 5 × SABCD
🔍 严密推导五步法 (公式清晰展示)
1 看左角 △EAH：连辅助线 ED。
因 HD = DA，ED 为中线，则 S△EDH = S△EAD；
因 EA = AB，DA 为 △EBD 中线，则 S△EAD = S△ABD。
故 S△EAH = 2 S△ABD。
2 看其余三角同理：连 AF, DF, CH 中线：
• S△FBE = 2 S△ABC
• S△GCF = 2 S△BCD
• S△HDG = 2 S△ADC
3 四周 4 角求和：
2(S△ABD + S△BCD) + 2(S△ABC + S△ADC)
= 2 SABCD + 2 SABCD = 4 SABCD。
4 大四边形总面积：
SEFGH = SABCD + 4 SABCD = 5 SABCD。
5 计算最终面积：
SABCD = 66 ÷ 5 = 13.2 平方米。

🪟 等积模型（拉窗帘）核心要领

两平行线之间的垂直距离（高）处处相等。当三角形的底固定在一条线上，顶点在另一条线上左右滑动时，就像拉窗帘一样，形状虽然剧烈变化，但底和高从未改变！

核心公式：
S = ½ × 底 b × 高 h （面积处处相等）

• 不规则多边形等积化简：遇到复杂的凹凸四边形，可以通过平行线滑动顶点，将其转化为简单的等积三角形。

• 梯形两腰三角形等积：在梯形 ABCD（AD // BC）中，△ABC 与 △DBC 同底等高同积，减去公共底 △OBC 后，立刻能证明两腰翅膀面积相等（即蝴蝶模型梯形性质）！

形态 A：底为一边，顶在对边
S阴影 = ½ × S平行四边形

课堂例 12 · 一半模型等量代换 秒杀答案：34

长方形内双“一半模型”重叠抵消

如图，一个长方形被一些直线分成了若干个小块，已知 △ADG 的面积是 11，△BCH 的面积是 23，求中间四边形 EGFH 的面积。
第一步（找两个一半）：大三角形 △FDC 底为 DC、高为长方形宽，占长方形面积的 ½；同理，左右两个三角形 △ADE + △BCE 的底之和也是 DC、高也是宽，加起来也占长方形的 ½！
第二步（等式相减消去公共块）：
S△FDC = S△ADE + S△BCE。
两边同时减去下方的两个空白小三角形 △DGE 和 △EHC，剩下的部分依然相等！
🎯 结论：S四边形EGFH = S△ADG + S△BCH = 11 + 23 = 34！
课堂例 15 · 一半模型 + 容斥重叠 秒杀答案：10

长方形内阴影总和为 70，求中心四边形 EFGO

如图，长方形 ABCD 内的阴影部分面积之和为 70，AB = 8，AD = 15，求中间空白四边形 EFGO 的面积。
第一步（算长方形与顶部△AOD）：S长方形 = 15 × 8 = 120。对角线把长方形平分四份，顶部阴影 S△AOD = 120 ÷ 4 = 30。
第二步（锁定一半模型 △AFD）：空白大三角形 △AFD 底为 AD、高为宽，面积等于长方形的一半 = 60；因此它外侧的两块大直角三角形 △ABF + △DCF 面积和也等于 60！
🎯 第三步（容斥原理秒杀）：观察下半部分，S△DBC = 60。由课堂板书：阴影① + 阴影② + 30 + 四边形 x 刚好比长方形的一半（60）多出一个 x！
故 x = 阴影总和 70 − 60 = 10！

🦋 梯形蝴蝶 & 风筝模型三大法则诊断
法则 1（梯形蝴蝶）：左翅 = 右翅 (S₃ = S₄) 当前相等 ✓
仅当上下底平行（梯形 AD // BC）时成立！若上底:下底 = a : b，则四块份数比为 a² : b² : ab : ab，梯形总份数 = (a + b)²！
法则 2（风筝性质①）：头 × 尾 = 翅 × 翅 始终相等 ✓
课堂上把任意四边形对角线模型称为“风筝模型”。即便不平行（S₃ ≠ S₄），由等高底比 S₁/S₃ = DO/BO = S₄/S₂，交叉相乘恒有 S₁ × S₂ = S₃ × S₄！
法则 3（风筝性质②）：对角线比 = 两侧面积和之比 课堂重点 ★
AO : OC = (S₁ + S₃) : (S₄ + S₂) = S△ABD : S△CBD
DO : OB = (S₁ + S₄) : (S₃ + S₂) = S△ACD : S△ACB
当前 AO:OC = 1.00 : 1.00

课堂例 6 & 例 7 · 风筝两大性质 例6答: 21 / 例7答: 2倍

风筝模型性质①（交叉积）与性质②（对角线比）

【例6】四边形土地总面积 52 公顷，对角线分成 4 个小三角形，相邻两块为 6 和 7 公顷，求最大一块三角形面积。
【例7】四边形 ABCD 中，S△ABD = 13 S△BCD，且 AO = 2，DO = 3，求 CO 是 DO 的几倍？
【例6 解析】设另外两块为 a（下）和 b（左）。
① 剩下的面积和：a + b = 52 − 6 − 7 = 39；
② 风筝性质①（对顶乘积相等）：6a = 7b ⇒ a : b = 7 : 6。
按比例分配：a = 39 × 77+6 = 21 公顷（最大块）。
🎯 【例7 解析】直接用风筝性质②：
AOOC = S△ABDS△BCD = 13。已知 AO = 2，则 OC = 2 × 3 = 6。
故 CO ÷ DO = 6 ÷ 3 = 2 倍！
课堂例 8 · 格点点阵 + 风筝交点 🔥 秒杀答案：12/11

阴影顶点不在格点上？构造格点风筝求交点比！

如图，5×4 点阵中相邻两个格点间的距离是 1，阴影三角形 △ABO 的右下方顶点 O 是连线 AC 与 BD 的交点，求阴影面积。

BO : OD = S△ABC : S△ACD = 2 : 3.5 = 4 : 7！

课堂例 10 · 梯形蝴蝶总份数 (a+b)² 秒杀答案：25/4

梯形蝴蝶四块比 a² : b² : ab : ab 与总份数 (a+b)²

如图，在梯形 ABCD 中，AB // CD，对角线相交于点 O。已知下底 AB = 5，上底 CD = 3，且梯形总面积为 16，求下底 △AOB 的面积。
第一步（写四块份数）：上底 a = 3，下底 b = 5。
• 上三角 = 3² = 9 份；下三角 = 5² = 25 份；
• 左翅 = 右翅 = 3 × 5 = 15 份。
第二步（总份数完全平方公式）：
总份数 = (a + b)² = (3 + 5)² = 64 份（即 9 + 25 + 15 + 15 = 64）。
1 份的面积 = 16 ÷ 64 = 14。
🎯 第三步（求 △AOB）：S△AOB = 25 份 × 14 = 254（或 6.25）！

课堂例 13 · 正方形中点 1:2 沙漏设份数 秒杀答案：1 cm²

正方形面积为 3，M 为 AD 中点，12 份法求双翼阴影

如图，正方形 ABCD 的面积为 3 平方厘米，M 是 AD 边上的中点。连接 AC、BM、CM，求图中两块阴影三角形面积之和。
第一步（找梯形 ABCM 中的 1:2 沙漏）：AM // BC，且 AM : BC = 1 : 2。
由梯形蝴蝶/沙漏定理：S△AGM = 1² = 1份，S△BGC = 2² = 4份，两翼 S△ABG = S△MCG = 1×2 = 2份！
第二步（算正方形总份数）：对角线 AC 平分正方形，上半 △ABC = 2 + 4 = 6 份，故整个正方形 = 6 × 2 = 12 份！（右下 △CDM = 3 份）
🎯 第三步（求阴影）：两块阴影共 2 + 2 = 4 份（占正方形的 412 = 13）。
故 S阴影 = 3 × 13 = 1 平方厘米！

课堂例 11 · 三方向内缩鸟头 🔥 秒杀答案：24 cm²

三个角同时用鸟头，整体“1 减空白”逆推总面积

如图，已知中间 △DEF 的面积为 7 平方厘米，且 BE = CE，AD = 2BD，CF = 3AF，求大三角形 △ABC 的面积。
第一步（三个顶角分别套鸟头公式）：
• 顶角 A：S△ADFS△ABC = 2 × 13 × 4 = 16；
• 左角 B：S△BDES△ABC = 1 × 13 × 2 = 16；
• 右角 C：S△CFES△ABC = 3 × 14 × 2 = 38。
🎯 第二步（整体减空白）：中心 △DEF 占比 = 1 − (16 + 16 + 38) = 1 − 1724 = 724。
故 S△ABC = 7 ÷ 724 = 24 cm²！
课堂例 13 · 三向外扩风车鸟头 🔥 秒杀答案：18

题目12的三角形姊妹篇：顺次延长三边求外扩面积

如图，已知 △ABC 面积为 1，延长 AB 至 D 使 BD = AB；延长 BC 至 E 使 CE = 2BC；延长 CA 至 F 使 AF = 3AC，求大 △DEF 的面积。
第一步（找 3 组互补角鸟头）：外围三个大三角形与中心 △ABC 在顶点 A、B、C 处分别角互补（相加 180°）！
第二步（连用 3 次乘积比）：

• 下翼 △BDE：夹边比 (BD/AB) × (BE/BC) = 1 × (2+1) = 3。
🎯 第三步（四块求和）：S△DEF = 1 + 6 + 8 + 3 = 18！

课堂例 2 · 双燕尾求第三边比 秒杀答案：27 : 16

已知两边分点比，连用两次燕尾求第三边 AF : FB

如图，在 △ABC 中，三条线交于点 G，已知 BD : DC = 4 : 9，CE : EA = 4 : 3，求 AF : FB。
第一步（设右翼份数）：因 AE : EC = 3 : 4，设 S△AGE = 3份，S△CGE = 4份，则右翼大燕尾 S△AGC = 3 + 4 = 7份。
第二步（用下开口燕尾求左翼 △ABG）：
S△ABGS△ACG = BDDC = 49 ⇒ S△ABG = 7 × 49 = 289 份。
再用右开口燕尾：S△ABGS△CBG = AEEC = 34 ⇒ S△CBG = 289 × 43 = 11227 份。
🎯 第三步（用左开口燕尾求 AF : FB）：
AFFB = S△ACGS△BCG = 7 ÷ 11227 = 2716（即 27 : 16）！
课堂例 3 · 残缺燕尾添辅助线 🔥 秒杀答案：11/30

只有两条交叉线？主动连 CF 补全燕尾 + 设 1 份法！

如图，△ABC 面积是 1，E 是 AC 中点（1:1），BD : DC = 1 : 2，AD 与 BE 交于点 F。求右下角四边形 DFEC 的面积。
第一步（添辅助线 CF，设最小块为 1 份）：连接 CF！
设左下最小块 S△BDF = 1 份。因 BD:DC = 1:2，则 S△CDF = 2 份。
第二步（连用两次燕尾推全图）：
• 右开口燕尾：S△ABFS△CBF = AEEC = 11 ⇒ S△ABF = 1 + 2 = 3 份！
• 下开口燕尾：S△ABFS△ACF = BDDC = 12 ⇒ S△ACF = 3 ÷ 2 = 32 份（平分给 △AFE 和 △CFE 各 34 份）。
🎯 第三步（按份数占比结算）：全图总份数 = 3 + 1 + 2 + 32 = 152 份；四边形 DFEC = 2 + 34 = 114 份。
故 SDFEC = 11/415/2 = 1130！
课堂例 4 · 六块知四列双燕尾 秒杀答案：315

△ABC 被分成 6 个小三角形，已知 4 块面积求全局

如图，△ABC 被 3 条交于点 O 的塞瓦线分成 6 个小三角形，已知其中 4 个的面积分别为 84、35、30、40，求 △ABC 的总面积。
第一步（由下底 40 和 30 得 BD : DC = 4 : 3）：
设左中未知块为 x，右上未知块为 y。
由下开口燕尾：S△ABOS△ACO = 84 + x35 + y = 4030 = 43 ①。
第二步（由右开口燕尾消去 84+x）：
S△ABOS△CBO = 84 + x40 + 30 = y35 ⇒ 84 + x = 2y ②。
代入①式：2y35 + y = 43 ⇒ 6y = 140 + 4y ⇒ y = 70，进而 x = 56！
🎯 第三步（六块相加）：S△ABC = 84 + 56 + 40 + 30 + 35 + 70 = 315！

小学六大几何模型速查全景图

点击任意模型卡片底部的「进入动态画板」，即可直达对应篇章并拖拽图形深度探索！

🪟

1. 等积模型

别名：拉窗帘模型
S = ½ × b × h （同底等高）

平行线间距离（高）处处相等。顶点沿平行线滑动时，底与高不变，面积处处相等。

🌓

2. 一半模型

矩形与平行四边形
S(阴影) = ½ × S(平行四边形)

底为一边顶点在对边，或内部任意点向四顶引线上下和等于一半。

🦋

3. 蝴蝶模型

对角线交叉四分法
头 × 尾 = 翅 × 翅 (S₁×S₂ = S₃×S₄)

任意四边形对顶积相等；梯形中左右两翅膀面积完全相等！

⏳

4. 沙漏模型

X 相似比定理
S(上) / S(下) = (a / A)²

两底平行的交叉相似图形，面积比等于对应边长比的平方。

🐦

5. 鸟头模型

共角 / 互补角定理
S(小) / S(大) = (a × b) / (A × B)

两三角形共角或互补，面积比等于夹角两边乘积之比。题目12核心！

🕊️

6. 燕尾模型

三角形内点三射定理
S₁ / S₂ = S₃ / S₄ = d₁ / d₂

左右两大大三角形之比等于下方两小三角形之比，且等于底边截比。
