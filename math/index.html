图形的变化充满奇妙的规律！本专题精选三道充满智慧的经典几何挑战题：从内接正方形的面积翻倍与比例，到平行线与多边形面积，再到趣味等面积分割，带你领略几何的对称与平衡之美。

📌 题目 7：三角形内接正方形与高线比例模型 已实装 · 互动实验室
正方形 DEFG 的边 EF 在 △ABC 边 BC 上，顶点 D, G 分别在 AB, AC 上，高 AH = 40cm，BC = 60cm，求正方形边长。
A字型相似 高线比等于相似比 “积除以和”秒杀公式
🔒 题目 8：平行线分线段成比例与四边形面积模型 第二阶段上线
点 D 在 BC 上，DE // AB，且 AF/FB = CE/AE。证明 DF // AC；若 BD:DC = 1:2，S△ABC = 18cm²，求四边形 AEDF 面积。
平行线分线段 平行四边形性质 面积比等于相似比平方
🔒 题目 9：平行截割线与等面积/等周长分割模型 第三阶段上线
△ABC 中 AB = 5, BC = 6, AC = 7，DE // BC。若 △ABC 面积（或△ADE）与梯形 BCED 面积相同，求 DE；若周长相同，求 DE。
面积二等分点 等周长方程 方程思想求解
