1 连结 AD，把蛋糕切成两块
底边 BD : DC = 1 : 2，高完全相同！总面积 18 分成 3 份（每份是 6）：
  • 左边蛋糕 △ABD = 6 cm²
  • 右边蛋糕 △ADC = 12 cm²
2 平行线切斜边：1 份对 2 份
因为 DE // AB，底边是 1:2，斜边 AC 也是 AE : EC = 1 : 2！ 右边面积为 12 的蛋糕，再分成 3 份（每份是 4）：
👉 △ADE 占 1 份，面积 = 12 ÷ 3 = 4 cm²！
3 平行四边形两边一模一样
四边形 AEDF 是平行四边形，对角线 AD 把它对半分开成两个完全一样的三角形：
👉 另一半 △ADF 的面积也必定是 4 cm²！
4 两半合体，口算一步秒出
平行四边形 AEDF 的总面积就是两块小三角形相加：
S = 4 + 4 = 8 cm²！
不用算平方，四年级小朋友口算就能秒杀！

高同底比定面积，连线切大再切小！对角线分平行四边形，对半分合算得巧！

S = 18 × 1/3 × 2/3 × 2 = 8 cm²
💡 进阶比例线段与相似推导
🔹 第 (1) 问：证明 DF // AC
因为 DE // AB，由平行线分线段成比例定理：CE / AE = CD / DB。
已知条件：AF / FB = CE / AE。
等量代换得：AF / FB = CD / DB ⟹ BF / FA = BD / DC。
由平行线分线段成比例定理的逆定理，可证：DF // AC。
两组对边分别平行，故四边形 AEDF 是平行四边形。
🔹 第 (2) 问：相似三角形面积比等于相似比平方
因为 DE // AB，所以 △CDE ∽ △CBA，相似比为 CD / CB = 2 / 3：
S△CDE = (2/3)² · S△ABC = (4/9) · 18 = 8 cm²。
同理 DF // AC，△BDF ∽ △BCA，相似比为 BD / BC = 1 / 3：
S△BDF = (1/3)² · S△ABC = (1/9) · 18 = 2 cm²。
大三角形减去两个角上的小三角形：
SAEDF = 18 - 8 - 2 = 8 cm²！
