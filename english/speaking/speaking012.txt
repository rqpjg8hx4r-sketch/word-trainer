Q: Do you like using these things in your daily life? Say why or why
not.

A: There are five different things: money, a hat, a backpack, a mobile
phone, and a game console.

I like using money because I can buy things I need.

I like wearing a hat because it can protect me from the sun.

I like using a backpack because it is big. I can put books and other things in it.

I like using a mobile phone. It is a multi-function tool. I can use a mobile phone to make phone calls and take pictures. 

I don’t like using a game console because I prefer playing video games on my iPad.
