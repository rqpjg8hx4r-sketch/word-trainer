🏮 密道走廊的奇妙灯阵

长廊里有 n 盏亮着的灯，从 1 到 n 依次按顺序编号。按一次灭，再按一次亮。
第 1 个人 把所有 2 的倍数 的灯全按了一次（偶数灯熄灭）；
第 2 个人 把所有 3 的倍数 的灯全按了一次（3、9亮变灭，6灭变亮！）。
最终，哪几盏灯还奇迹般地保持 亮着？让我们用计算机的眼睛看透每盏灯的命运！

💡 状态分析透视：
• 最初：所有灯亮（按动 0 次，状态为亮）
• 只被 2 整除的灯（如 2, 4, 8）：按动 1 次 ➡️ 灭
• 只被 3 整除的灯（如 3）：按动 1 次 ➡️ 灭
• 既被 2 又被 3 整除的灯（如 6, 12）：按动 2 次（按灭又按亮） ➡️ 亮！
• 既不被 2 也不被 3 整除的灯（如 1, 5, 7）：按动 0 次 ➡️ 亮！
阶段 1 · 变量初始化
全亮灯池与输入读取
n = int(input()) # 1~n 盏灯，初始全为亮(True) # 索引 0 占位不用，1~n 对应编号 lights = [True] * (n + 1)
输入 n，准备一个布尔列表。下标 1~n 对应每盏灯的开闭状态。
阶段 2 · 第 1 人巡视
2 的倍数全部反转
# 第1人：步长为2，按下所有的偶数灯 for i in range(2, n + 1, 2): lights[i] = not lights[i]
每隔 2 盏灯巡查一次：原先亮着(True)被按灭为(False)。
阶段 3 · 第 2 人巡视
3 的倍数全部反转
# 第2人：步长为3，按下所有的3倍数灯 for i in range(3, n + 1, 3): lights[i] = not lights[i]
每隔 3 盏灯巡查一次：原先灭的按亮，原先亮的按灭（not lights[i] 取反）。
阶段 4 · 收集亮灯结果
筛选 True 状态的编号
ans = [] for i in range(1, n + 1): if lights[i]: ans.append(i)
遍历 1 到 n，只要灯依然是 True，就记录进答案清单。
阶段 5 · 格式化标准输出
换行逐个输出
for x in ans: print(x)
完全契合题目样例要求，依次换行打印每个幸存亮灯的编号。

n = int(input()) # lights[i] 表示第 i 盏灯的状态，True为亮，False为灭 # 长度取 n + 1，方便下标 1~n 直接对应灯编号 lights = [True] * (n + 1) # 第一个人：将2的倍数的灯全部按下 for i in range(2, n + 1, 2): lights[i] = not lights[i] # 第二个人：将3的倍数的灯全部按下 for i in range(3, n + 1, 3): lights[i] = not lights[i] # 输出所有亮着灯的编号 for i in range(1, n + 1): if lights[i]: print(i)
