阶段 1 · 字符串切分读取
input().split(",")
a = input().split(",") ls = []
第一行接收逗号分隔的8个包裹，通过 split(",") 切割为字符列表 a，并创建空列表 ls。
阶段 2 · 遍历过滤与去重
for i in a: if i not in ls
for i in a: num = int(i) if num not in ls: ls.append(num)
逐一检查每个包裹重量。若该数值尚未收录到 ls 中，则转换为整数追加进去；重复的直接忽略。
阶段 3 · 降序从大到小排序
ls.sort(reverse=True)
k = int(input()) ls.sort(reverse=True)
输入目标第 k 重。调用 sort(reverse=True)，将去重后的重量从大到小排列，第1大在下标0。
阶段 4 · 超界判断守卫
if k > len(ls) 边界检测
if k > len(ls): print('None')
如果 k 大于去重后总品种数 len(ls)，说明根本没有第 k 重，安全输出 'None'。
阶段 5 · 精准定位输出
print(ls[k - 1])
else: print(ls[k - 1])
因为 Python 索引从 0 开始计数，第 k 重对应的恰好是下标 k - 1！
